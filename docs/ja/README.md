このプロジェクトは、オリジナルの `iRon` オーバーレイを大幅に拡張したバージョンです。オリジナルプロジェクトの核心的な理念である「極めて軽量で、外部ランタイムへの依存関係がないこと」を維持しつつ、iRacingプレイヤーにとって必須となる強力な機能を追加しています。

> **オリジナルの iRon プロジェクト（lespalt作）に基づく:** [https://github.com/lespalt/iRon](https://github.com/lespalt/iRon)

<br>

### ✨ オリジナルの iRon との違い

**1. 💾 グローバルレイアウト自動保存**
* オリジナルの iRon では、アプリケーションを再起動するたびにウィンドウ位置がリセットされてしまう問題がありました。
* **iRon-Advanced** は、画面座標レイアウト、ウィンドウサイズ、オーバーレイの表示状態（On/Off）を Windows の `Documents\iRon_Advanced\config.json` パスに保存します。再起動すると、前回のレイアウトが完璧に復元されます！

**2. 📊 強化されたスタンディングとテレメトリ**
* 競合ドライバーの出身国をすばやく識別できるように、Standings オーバーレイのドライバー名の直前に **3文字の国名コードバッジ**（例: `[KOR]`, `[USA]`）を追加しました。
* 極めてプロフェッショナルで整理された外観にするため、冗長な車種名のテキストを整理しました。
* Relative オーバーレイに、Eloレーティングシステムに基づいた **リアルタイムの予想iRating変動値（+/-）** を直接追加しました。

**3. 🚀 新しく追加されたオーバーレイ:**
* **左右ビジュアルスポッター（新規）:** 死角に対する視覚的な警告です。左右のパネルは分割されており、個別にドラッグやサイズ変更が可能です！自車の横にいる車の実際の近接距離に基づいて**黄色**または**赤色**に点滅し、周囲に車がいないときは100%透明になります。
* **レーダー（近接レーダー）:** 視界を妨げないよう、近くに車がいないときは完全に透明になるトップダウン形式の近接レーダーです。
* **インシデント警告（スマートインシデント）:** 前方 150m 以内で発生したクラッシュに対して、点滅する警告バナーと正確な距離を表示します。
* **トラフィック（マルチクラストラフィック）:** 後方からより速いクラスの車両が接近した際に、ラップタイムペースの差に基づいて動的に青旗（ブルーフラッグ）UIを表示します。

## 📺 オーバーレイ

### *Relative*
iRacing の *Relative* ボックスに似ていますが、ライセンス、iRating、最後のピットストップからの周回数、現在のクラスの参加者に対する **リアルタイムの予想iRating変動値** などの追加情報が表示されます。また、バディリスト（Buddy list）に名前を追加することで、フレンドをハイライト表示することもできます。
上部にはオプションのミニマップが表示されます。相対モード（自車が中央に固定）または絶対モード（スタート/フィニッシュラインが中央に固定）のいずれかに設定できます。

![relative](https://github.com/lespalt/iRon/blob/main/relative.png?raw=true)

### *DDU*
iRacing 内で通常は様々なボックスを切り替えて確認しなければならない重要な情報を集約したダッシュボードです。
燃料計算機には、推定残りの周回数、残りの燃料量、1周あたりの推定燃料消費量、完走までに必要な推定_追加_燃料量、および次のピットストップで給油が予定されている燃料量が表示されます。

![ddu](https://github.com/lespalt/iRon/blob/main/ddu.png?raw=true)

### *Inputs*
スロットル/ブレーキ/ステアリングを動的なグラフで表示します。一貫したトレイルブレーキの練習に非常に役立ちます。

![inputs](https://github.com/lespalt/iRon/blob/main/inputs.png?raw=true)

### *Standings*
セーフティレーティング、iRating、最後のピットストップからの周回数（「ピット経過周回数」）、および各ドライバー名の左側にすっきりとした **国名コードバッジ** を含む、フィールド全体の順位を表示します。主にコーション期間中やレース前に競争レベルを把握するのに役立ちます。

![standings](https://github.com/lespalt/iRon/blob/main/standings.png?raw=true)

### *Cover*
これについてはスクリーンショットを省略します。シンプルな無地の黒い長方形で、Next-Gen NASCAR のような気を取られやすいゲーム内ダッシュボードを覆い隠すのに便利です。

### *Spotter (新規)*
車の死角に他車がいる場合に、画面の左右に色付きの長方形を描画するビジュアルスポッターです。
* 左右のパネルは、**個別に設定、移動、サイズ変更が可能**です。
* 周囲の車に対しては**黄色**の警告バーを表示し、危険な距離（<= 2.2m）まで接近すると鮮やかな**赤色**の警告バーに変化します。
* デフォルトでは完全に透明で、レイアウト編集が有効な間のみ半透明になります。

![spotter](../../screenshot_placeholder_spotter.png)

### *Radar (新規)*
周囲の車両を上から見下ろした視点（トップダウン）で描画する近接レーダーです。
* 画面の明瞭さを保つため、周囲に車がいないときはデフォルトで 100% 透明のままになります。
* 周囲の車両が近接範囲に入ると有効化され、トップダウンビューを描画します。

![radar](../../screenshot_placeholder_radar.png)

### *Incident Warning (新規)*
スマートインシデント警告システムです。単なる一般的な黄旗（イエローフラッグ）バナーを表示するのではなく、コーション中に前方の車がコースアウトしたかどうかを計算します。前方 150 メートル以内でクラッシュまたはコースアウトした車両が検出されると、クラッシュした場所までの距離を明記した、目立つ点滅警告バナーを表示します。

![incident](../../screenshot_placeholder_incident.png)

### *Multiclass Traffic (新規)*
マルチクラスレース用の動的な青旗警告システムです。周囲の車両の推定ラップタイムとあなたのラップタイムを比較します。より速いクラスの車両が後方から危機的なタイム差まで接近すると、視界を遮ることなく警告するために、青と白で激しく点滅する段階的なグローUIが作動します。

![traffic](../../screenshot_placeholder_traffic.png)

### *Head to Head (新規)*
自車のすぐ前方および後方のドライバーとのリアルタイムの比較を表示します。直前の周回での順位、名前、ギャップ、ラップタイム、およびセクタータイム（S1、S2、S3）を表示します。
* 直接のライバルと比較して、どこでタイムを失っているか、あるいは得ているかを監視するのに非常に役立ちます。
* 自分の行を目立たせるハイライトバンド機能を備えています。

### *Bomb Avenge (新規)*
あなたに衝突したドライバーのリアルタイム追跡情報を表示します。
* 衝突によってインシデントカウントが増加した際に自動的に作動します。
* 加害者の名前、現在のレース順位、およびリアルタイムの距離ギャップ（メートル）を表示します。
* *Relative* オーバーレイでは、加害者の行が赤く点滅し、カーナンバーの背景が赤になり、名前に `[BOMB]` がプレフィックスとして追加されます。

## 🚀 インストールと実行

アプリはインストールを必要としません。実行ファイル（`.exe`）を任意のフォルダにコピーするだけです。

使用するには、実行ファイルをダブルクリックするだけです。iRacing を起動する前と後のどちらで行っても問題ありません。コンソールウィンドウがポップアップし、iRon が実行中であることを示します。iRacing で車に乗ると、オーバーレイが表示されます。iRacing を **ボーダーレスウィンドウ（Borderless Window）** モードで実行することを強くお勧めします。

---

## ⚙️ 設定

オーバーレイを配置およびサイズ変更するには、**ALT-J** を押します。これによりレイアウト編集モードに入り、マウスでオーバーレイを移動したり、右下の角をドラッグしてサイズ変更したりできます。もう一度 **ALT-J** を押すと、通常モードに戻ります。

オーバーレイは、起動時に表示されるホットキーを使用して実行中にオン/オフを切り替えることができます。すべてのホットキーは設定可能です。

レイアウトと設定は自動的かつグローバルに以下に保存されます：
`Documents\iRon_Advanced\config.json`

### デフォルトのホットキー割り当て:
* **ALT-J**: 移動およびサイズ変更モード（レイアウト編集）
* **Ctrl-Space**: スタンディング（Standings）の切り替え
* **Ctrl-1**: DDU（ダッシュボード）の切り替え
* **Ctrl-2**: インプット（ペダルグラフ）の切り替え
* **Ctrl-3**: Relative ボックスの切り替え
* **Ctrl-4**: Cover ボックスの切り替え
* **Ctrl-5**: スポッター（左右同期）の切り替え
* **Ctrl-6**: 近接レーダーの切り替え
* **Ctrl-7**: インシデント警告の切り替え
* **Ctrl-8**: タイヤダッシュ（Tire Dash）の切り替え
* **Ctrl-9**: Head to Head ウィジェットの切り替え
* **Ctrl-0**: Bomb Avenge ウィジェットの切り替え
* **Ctrl-Shift-D**: グローバル表示モードの切り替え（レースのみ / リプレイのみ / 両方）

## 🛠️ ソースからのビルド

このアプリは Visual Studio 2022 で構築されています。検証はしていませんが、無料バージョンで十分なはずです。プロジェクト/ソリューションファイルはそのまま動作するはずです。Visual Studio のセットアップによっては、DirectX アプリケーションのビルドに必要な追加の必須コンポーネント（静的ライブラリ）のインストールが必要になる場合があります。

---

## 📦 依存関係

DirectX などの標準的な Windows コンポーネント以外に、実行時の依存関係はありません。これらは iRacing を実行できるほぼすべてのシステムにすでに存在しているはずです。ビルドの依存関係（特に iRacing SDK と picojson）は最小限に抑えられており、リポジトリに含まれています。
